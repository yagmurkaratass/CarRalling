# Changelog

## Unreleased

### Added

- 20-stage career with chapter briefings and completion rewards
- Persistent joker rights that prevent a crash or emergency fuel failure
- Seasonal biomes with spring animals, summer heat, autumn fog and winter ice
- Unlock progression for patterns and five vehicle classes
- Automated gameplay logic tests and GitHub Actions configuration

### Changed

- Rebalanced the opening chapters with full starting fuel, slower traffic and fewer hazards
- Reworked vehicle unlock thresholds to align with career milestones
- Replaced random early difficulty spikes with stage-based progression

### Removed

- Police chase mechanics that did not fit the main story
